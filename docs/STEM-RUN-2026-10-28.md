### 4.1 Failures and fixes

Two tracks have `[ ]` in their filenames:

- `Elissa/Elissa - 2006 Bastannak/13.Kermalak [Remix].mp3`
- `Fadl Shaker/14.Ba’da Aalbal.2009/03.Gowwa El Rouh [Duo With Elissa].mp3`

`gcloud storage cp` interprets `[ ]` as a wildcard in both the source URI and
the local destination, so the first two passes failed before Demucs started.
Fixes (committed):

| Commit | Change |
|---|---|
| `f676e4f` | escape `[`, `*`, `?` in the source GCS URI |
| `16e0f80` | download to a wildcard-free temp name (`source.mp3`) |

The third pass retried only the two failed rows: `separated=2 skipped=212
failed=0`.

`failed`/`stale`):

```bash

    --inventory work/lyrics/inventory.csv \
    --device cuda --max-minutes 0 --max-failures 5
```

Do not run two writers against the same prefix. Do not edit manifest rows by
hand.
