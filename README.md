# yue2-karaoke-align

An independent feasibility spike: **can we get word/phrase-level lyric
highlighting (karaoke) for songs generated by the sibling project**
[`maqamrock-yue2-lora-finetuning`](../maqamrock-yue2-lora-finetuning)?

Suno's studio editor does this natively. This repo asks whether *our* workflow
can, and what it would actually cost. It is **docs-first**: a phased plan, an
honest assessment, and one runnable CPU check. No model code yet, on purpose.

## Verdict (short)

- **Post-hoc alignment is plausible, but it is NOT the easy win it looks like.**
  Speech-ASR aligners (WhisperX, stable-ts) hallucinate and loop on *sung*
  audio — that is their expected failure mode, not bad luck. True **forced**
  alignment with a fixed transcript (MFA, Charsiu, aeneas) belongs to a
  different family: it cannot invent content, only mis-time it. Still gated by
  vocal-separation quality and the lack of a singing-trained Arabic acoustic
  model. Reopened as **Track A**, gated by a one-track trial.
  See [docs/ROUTE-A.md](docs/ROUTE-A.md).
- **The native route** (read the alignment out of the generation itself) is
  **doable as a demo, a headache as a production feature**: ~3–5 days to a
  base-model demo, ~1–2 weeks with real uncertainty to make it faithful to our
  own LoRA renders. See [docs/FEASIBILITY.md](docs/FEASIBILITY.md).
- **The browser player is trivial** (~half a day) and is independent of how the
  timings are produced. It can be built immediately against placeholder timings.

## Why this might work at all

YuE2's AR stream is conditioned on the diacritized lyric tokens and emits a
25 Hz semantic token stream — the only ~375 bit/s channel from text to audio.
The model renders `سِ` differently from `سٍ`, so a per-syllable lyric→frame
correspondence *causally exists* in the generation. It is never written to any
output file (the runtime exports no attention), so it has to be **tapped, not
found**.

## Relationship to the sibling project

Standalone. This repo **consumes** the sibling's rendered audio + prompt lyrics
(read-only) and **never modifies it** — no training, datasets, GCS, or
`INFERENCE/` scripts. See [docs/PARENT-CONTEXT.md](docs/PARENT-CONTEXT.md).
